    HTML基础

    HTML简介

    HTML(Hyper Text Markup Language)超文本标记语言是一种标记语言(markup language),使用标记标签(markup tag)来描述网页

    HTML标签由尖括号包围,成对出现,第一个叫做开始(开放)标签,第二个叫做结束(闭合)标签,例如<html>和</html>

    HTML文档包含HTML标签和纯文本,它是用来描述网页

    <html> 与 </html> 之间的文本描述网页
<body> 与 </body> 之间的文本是可见的页面内容
<h1> 与 </h1> 之间的文本被显示为标题
<p> 与 </p> 之间的文本被显示为段落

    HTML编辑器

    想要编辑HTML很简单，只需在记事本里编辑好内容，另存为.htm或.html,然后在浏览器打开HTML文件即可。

    HTML属性

    属性为HTML元素提供附加信息。

    HTML 标签可以拥有属性。属性提供了有关 HTML 元素的更多的信息。

    属性总是以名称/值对的形式出现，比如：name=”value”。

    属性总是在 HTML 元素的开始标签中规定。
