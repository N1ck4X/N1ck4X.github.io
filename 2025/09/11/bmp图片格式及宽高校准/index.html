什么是bmp图片

BMP是英文Bitmap（位图）的简写，它是Windows操作系统中的标准图像文件格式，能够被多种Windows应用程序所支持。随着Windows操作系统的流行与丰富的Windows应用程序的开发，BMP位图格式理所当然地被广泛应用。这种格式的特点是包含的图像信息较丰富，几乎不进行压缩，但由此导致了它与生俱生来的缺点–占用磁盘空间过大。所以，目前BMP在单机上比较流行。

bmp文件结构

以010editor解析bmp文件为例

文件头部（BitmapFileHeader）


文件头部由14个字节（一个字节包含两个16进制位）组成，其中包含：

  1. bfType：文件类型标识（42 4D），也称魔术数字，占2个字节。对应的为BM。

  2. bfSize：占4个字节，表示文件的总字节数。

  3. bfReserved1\2：各占2个字节，必须为0。

  4. bfoffBits：占4个字节，这个值非常重要，它告诉你需要跳过多少字节才能找到真正的像素数据，其值=文件头（14）+信息头部（通常为40或56）+调色板大小（如果有的话）

位图信息头（BitmapInformationHeader）


也称信息头，长度通常为40个字节（也有可能为56个），它包含了图像的宽度，高度，像素数据区域的大小等
其中关键字段包括：

  1. BiSize：4字节，通常为40或56，用来验证bmp版本

  2. BiWidth：4字节

  3. BiHeight：4字节，可以是正数也可以是负数：
    正数: 表示图像是倒向的（bottom-up），即像素数据从图像左下角开始，到右上角结束。这是最常见的格式。
    负数: 表示图像是正向的（top-down），像素数据从图像左上角开始。这种格式比较少见，且不能使用压缩。

  4. BiBitCount(色深)：2字节，表示每个像素所需的数位（单位为比特）：
    1: 单色位图（每个像素1位，使用调色板，2种颜色）
    4: 16色位图（每个像素4位，使用调色板，16种颜色）
    8: 256色位图（每个像素8位，使用调色板，256种颜色）
    16: 高彩色位图（每个像素16位，通常为R5G6B5）
    24: 真彩色位图（每个像素24位，即8R+8G+8B，最常见）
    32: 带Alpha通道的真彩色（每个像素32位，通常为8A+8R+8G+8B）

  5. BiCompression：4字节，表示压缩方式：
    0 (BI_RGB): 无压缩。绝大多数BMP文件都是这种格式。
    1 (BI_RLE8): 用于8位位图的RLE压缩。
    2 (BI_RLE4): 用于4位位图的RLE压缩。
    3 (BI_BITFIELDS): 像素值直接使用位域掩码编码，常见于16位和32位位图。

  6. BiSizeImage：4字节，像素数据区域大小（注意字节数转像素数）

调色板 (Color Palette)

这是一个可选部分。只有当 biBitCount ≤ 8（即1位, 4位, 8位位图）时，才需要调色板。24位和32位的真彩色位图没有调色板，像素值直接表示颜色。调色板实际上是一个颜色查询表，它是一个数组，每个元素是一个 4 字节 的结构：

像素数据区存储的并不是实际的颜色值，而是这个调色板数组的索引。例如，在一个8位位图中，一个像素的值为 0x05，就意味着它使用的是调色盘中第5个 RGBQUAD 所定义的颜色。

实际的像素数据 (Pixel Data / Image Data)

这是文件的主体，存储了每一个像素的颜色信息。

**偏移位置：**由文件头中的 bfOffBits 指定。

排列顺序：
对于最常见的 biHeight > 0 的倒向位图，像素数据是从下到上，从左到右存储的。即文件中最先读到的是图像的最后一行像素，最后读到的是图像的第一行像素。

行对齐 (Padding)：
BMP格式规定，每一行像素数据的字节数必须是 4 的倍数。如果不是，则需要用 0x00 进行填充，使其达到4的倍数。

每行实际占用的字节数计算公式：
stride = floor((biWidth * biBitCount + 31) / 32) * 4;

**简化计算：**对于常见的24位位图（每个像素3字节），一行像素的理论长度是 width * 3。那么，需要填充的字节数为：
padding = (4 - (width * 3) % 4) % 4;
例如：一个宽度为5的24位位图，一行理论长度为 5 * 3 = 15 字节。15 % 4 = 3，所以需要填充 4 - 3 = 1 个字节的 0x00，使得这一行的总长度为16字节。

计算转换

1字节=8比特=2个16进制位
以24色深为例：
24（dec）=18(hex)，所以单个颜色值需要2个十六进制位储存
一个像素块由R/G/B三个颜色值组成，即需要6个十六进制位、3个字节储存
